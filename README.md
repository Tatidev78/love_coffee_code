# ☕ Love Coffee Code

A responsive coffee shop landing page built with **HTML5** and **CSS3** as part of my front-end learning journey.

This project was created to practice the fundamentals of web development, focusing on semantic HTML, CSS styling, responsive layouts, and page structure. It represents one of my first experiences building a complete website from scratch.

> **Note:** This project was developed during the early stage of my front-end learning journey. It remains in my portfolio to showcase my technical growth and learning progression.
